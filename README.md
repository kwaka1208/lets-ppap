# PPAP省力化プロジェクト

**しかたなくやらないといけないPPAPを、少しでも楽にするためのプロジェクトです。**

指定したフォルダ直下にあるサブフォルダごとに、中身をパスワード付きのZIPファイルへ一括圧縮し、ファイル名とパスワードの対応表をCSVで出力するツールです。パスワードの生成もすべて行います。

Windows版（`ppap.bat`）と Mac / Linux版（`ppap.sh`）があります。

> [PPAP](https://ja.wikipedia.org/wiki/PPAP_(%E3%82%BB%E3%82%AD%E3%83%A5%E3%83%AA%E3%83%86%E3%82%A3))（パスワード付きZIPでのファイル交換）を推奨するものではありません。とはいえ、取引先の指定によりPPAPしなければならないこともあるので、その業務負担を低減するために作成・公開しているものです。

## 主な機能

- **サブフォルダ単位での一括ZIP化**: 対象フォルダ直下の各サブフォルダの中身を `サブフォルダ名.zip` として圧縮します（空のフォルダは自動的にスキップされます）。
- **パスワードの自動生成**: 視認性の高いランダムな英数字（デフォルト12桁、判別しづらい `1` / `l` / `I` / `0` / `O` を除外）をフォルダごとに個別生成します。
- **パスワード一覧のCSV出力**: 圧縮したZIPファイル名とパスワードの組み合わせを `password_list_YYYYMMDD_HHMMSS.csv`（UTF-8 BOM付き・Excel対応）として出力します。
- **対象フォルダの指定**: Windows版は `ppap.bat` を置いたフォルダが対象です。Mac / Linux版はパス入力（ターミナルへのドラッグ＆ドロップ可）、カレントフォルダの自動選択に対応しています。

## 事前準備

### Windows版（`ppap.bat`）

圧縮処理に **7-Zip** を使用します。事前にインストールを行ってください。

1. [7-Zip公式サイト](https://7-zip.opensource.jp/) からインストーラーをダウンロードします。
2. 標準設定（`C:\Program Files\7-Zip\`）のままインストールします。

### Mac / Linux版（`ppap.sh`）

- **Mac**: 追加のインストールは不要です（標準で入っている `zip` と `perl` を使います）。
- **Linux**: `zip` と `perl` を使います。`zip` が入っていない場合はインストールしてください（例: `sudo apt install zip`）。
- 暗号化方式を `AES256` に変更する場合のみ、7-Zipが必要です（Mac: `brew install sevenzip`、Linux: `sudo apt install p7zip-full` など）。

## 使い方（Windows版）

1. 圧縮したいサブフォルダ群が入っている**親フォルダ**に、`ppap.bat` をコピーします。
2. `ppap.bat` をダブルクリックします。`ppap.bat` と同じフォルダにあるサブフォルダを対象に、自動的に処理が開始されます。

## 使い方（Mac / Linux版）

ターミナルで `ppap.sh` を実行します。以下は、ダウンロードフォルダに `ppap.sh` を保存した場合の例です。

### 1. フォルダを指定して実行

```bash
bash ~/Downloads/ppap.sh "/Users/username/Desktop/TargetFolder"
```

### 2. 対話形式で実行（カレントフォルダ／パス指定）
1. ターミナルで `bash ~/Downloads/ppap.sh` を実行します。
2. 対象フォルダのパス入力を求められます。
   - **カレントフォルダを対象にする場合**: 何も入力せずそのまま `Enter` キーを押します。
   - **任意のフォルダを対象にする場合**: フォルダパスを入力（またはターミナルに対象フォルダをドラッグ＆ドロップ）して `Enter` キーを押します。

## 入出力イメージ

### 実行前のフォルダ構成
```text
TargetFolder/
├── 顧客A資料/
│   └── 請求書.pdf
├── 顧客B資料/
│   └── 見積書.xlsx
└── 空フォルダ/
```

### 実行後のフォルダ構成
```text
TargetFolder/
├── 顧客A資料/
├── 顧客B資料/
├── 空フォルダ/
├── 顧客A資料.zip                         <-- パスワード付きZIP（中身は請求書.pdfのみ）
├── 顧客B資料.zip                         <-- パスワード付きZIP（中身は見積書.xlsxのみ）
└── password_list_20261119_123000.csv   <-- パスワード一覧CSV
```

### 出力されるCSVの内容
| ファイル名 | パスワード |
| :--- | :--- |
| 顧客A資料.zip | k9XmP4vR2nQw |
| 顧客B資料.zip | H7tY3bZ8cF5e |

## カスタマイズ

### Windows版（`ppap.bat`）

`ppap.bat` をテキストエディタで開き、冒頭の設定項目やオプションを編集することで動作を変更できます。

| 設定項目 / 箇所 | デフォルト値 | 説明 |
| :--- | :--- | :--- |
| `SEVEN_ZIP` | `C:\Program Files\7-Zip\7z.exe` | 7-Zipのインストール先が異なる場合にパスを変更します。 |
| `PASS_LENGTH` | `12` | 自動生成するパスワードの文字数を指定します。 |
| `-mem=ZipCrypto` | `ZipCrypto` | Windows標準のエクスプローラーで解凍できる暗号化方式です。より強固な暗号化が必要な場合は `-mem=AES256` に書き換えてください（解凍側にも7-Zip等が必要になります）。 |

### Mac / Linux版（`ppap.sh`）

`ppap.sh` をテキストエディタで開き、冒頭の設定項目を編集することで動作を変更できます。

| 設定項目 | デフォルト値 | 説明 |
| :--- | :--- | :--- |
| `PASS_LENGTH` | `12` | 自動生成するパスワードの文字数を指定します。 |
| `ENCRYPTION` | `ZipCrypto` | Windows標準のエクスプローラーで解凍できる暗号化方式です。より強固な暗号化が必要な場合は `AES256` に書き換えてください（7-Zipが必要です。解凍側にも7-Zip等が必要になります）。 |

## 注意事項

- **既存ファイルの上書き**: 出力先に同名の `.zip` ファイルが既に存在する場合、確認なしで上書きされます。
- **パスワードCSVの管理**: 出力されたCSVファイルには平文でパスワードが記載されています。外部への誤送信や共有フォルダへの放置にご注意ください。
- **文字コードについて**: `ppap.bat` を編集・保存する際は、文字コードを必ず **UTF-8** に設定してください（Shift-JIS等で保存すると日本語フォルダ名が正しく処理されない場合があります）。
- **Mac / Linux版のファイル名の扱い**: ZIP内の日本語ファイル名は、Windowsで解凍しても文字化けしない形式に補正して記録します。Macが自動で作る `.DS_Store` は圧縮対象から除外します。
