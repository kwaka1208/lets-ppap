# PPAP省力化プロジェクト

**しかたなくやらないといけないPPAPを、少しでも楽にするためのプロジェクトです。**

フォルダごとに、パスワード付きのZIPファイルをまとめて作るツールです。パスワードは自動で作られ、「どのZIPファイルに、どのパスワードを付けたか」の一覧表も一緒にできあがります。

Windows版（`ppap.bat`）と Mac / Linux版（`ppap.sh`）があります。

> [PPAP](https://ja.wikipedia.org/wiki/PPAP_(%E3%82%BB%E3%82%AD%E3%83%A5%E3%83%AA%E3%83%86%E3%82%A3))（パスワード付きZIPでのファイル交換）を推奨するものではありません。とはいえ、取引先の指定によりPPAPしなければならないこともあるので、その業務負担を低減するために作成・公開しているものです。

## できること

- **フォルダごとにZIPファイルを作ります**: フォルダの名前が、そのままZIPファイルの名前になります（例：「顧客A資料」フォルダ → 「顧客A資料.zip」）。中身が空のフォルダは飛ばします。
- **パスワードを自動で作ります**: ZIPファイルごとに、別々のパスワードを作ります。12文字の英数字で、「1」と「l」、「0」と「O」のような見分けにくい文字は使いません。
- **パスワードの一覧表を作ります**: ZIPファイルの名前とパスワードの組み合わせを、Excelで開ける一覧表（CSVファイル）に書き出します。

## はじめに準備すること

### Windows版

**7-Zip**（無料の圧縮ソフト）を使います。まだ入っていなければ、先にインストールしてください。

1. [7-Zip公式サイト](https://7-zip.opensource.jp/) から、インストール用のファイルをダウンロードします。
2. ダウンロードしたファイルを開き、インストール先は変えずに、そのままインストールします。

### Mac / Linux版

- **Mac**: 追加で入れるものはありません。
- **Linux**: `zip` コマンドを使います。入っていない場合はインストールしてください（例: `sudo apt install zip`）。

## 使い方（Windows版）

1. **作業用のフォルダを1つ用意します。**
   デスクトップなどに、新しいフォルダを作ってください（例：「送付用」）。
2. **ZIPにしたいフォルダと `ppap.bat` を、作業用のフォルダに入れます。**
   ZIPにしたいフォルダはいくつ入れてもかまいません。
3. **`ppap.bat` をダブルクリックします。**
   黒い画面が開いて、ZIPファイル作りが始まります。
4. **「すべての処理が終了しました。」と表示されたら、何かキーを押して画面を閉じます。**
5. **作業用のフォルダに、ZIPファイルとパスワードの一覧表ができています。**

## 使い方（Mac / Linux版）

「ターミナル」というアプリを使います。

1. **作業用のフォルダを1つ用意します。**
   デスクトップなどに、新しいフォルダを作ってください（例：「送付用」）。
2. **ZIPにしたいフォルダと `ppap.sh` を、作業用のフォルダに入れます。**
   ZIPにしたいフォルダはいくつ入れてもかまいません。
3. **ターミナルを開きます。**
   Macの場合は「アプリケーション」→「ユーティリティ」→「ターミナル」です。
4. **`bash` と入力し、半角スペースを1つ空けます。**
5. **作業用のフォルダに入れた `ppap.sh` を、ターミナルの画面にドラッグ＆ドロップして、`Enter` キーを押します。**
   画面には `bash /Users/（名前）/Desktop/送付用/ppap.sh` のように表示されます。`Enter` キーを押すと、ZIPファイル作りが始まります。
6. **「すべての処理が終了しました。」と表示されたら完了です。**
   作業用のフォルダに、ZIPファイルとパスワードの一覧表ができています。

## 使うとこうなります

作業用のフォルダ「送付用」に、ZIPにしたいフォルダを3つ入れた場合の例です。実行した後も、元のフォルダはそのまま残ります。中身が空のフォルダはZIPファイルになりません。

### Windows版の場合

**実行する前**

```text
送付用/
├── ppap.bat
├── 顧客A資料/
│   └── 請求書.pdf
├── 顧客B資料/
│   └── 見積書.xlsx
└── 空フォルダ/
```

**実行した後**

```text
送付用/
├── ppap.bat
├── 顧客A資料/
├── 顧客B資料/
├── 空フォルダ/
├── 顧客A資料.zip                      ← パスワード付きZIP（中身は請求書.pdf）
├── 顧客B資料.zip                      ← パスワード付きZIP（中身は見積書.xlsx）
└── password_list_20261119_123000.csv  ← パスワードの一覧表
```

### Mac / Linux版の場合

**実行する前**

```text
送付用/
├── ppap.sh
├── 顧客A資料/
│   └── 請求書.pdf
├── 顧客B資料/
│   └── 見積書.xlsx
└── 空フォルダ/
```

**実行した後**

```text
送付用/
├── ppap.sh
├── 顧客A資料/
├── 顧客B資料/
├── 空フォルダ/
├── 顧客A資料.zip                      ← パスワード付きZIP（中身は請求書.pdf）
├── 顧客B資料.zip                      ← パスワード付きZIP（中身は見積書.xlsx）
└── password_list_20261119_123000.csv  ← パスワードの一覧表
```

## 気をつけること

- **同じ名前のZIPファイルは上書きされます**: 作業用のフォルダに同じ名前のZIPファイルがすでにあると、確認なしで新しいものに置き換わります。
- **パスワードの一覧表の扱いに注意してください**: 一覧表には、パスワードがそのまま書かれています。ZIPファイルと一緒にメールで送ったり、共有フォルダに置いたままにしたりしないでください。
- **送る前に一度開けてみると安心です**: できたZIPファイルが、一覧表のパスワードで開けるか確かめてから送ってください。

## 設定を変えたいとき（詳しい方向け）

`ppap.bat` / `ppap.sh` をテキストエディタで開き、ファイルの最初のほうにある設定を書き換えると、動きを変えられます。

### Windows版（`ppap.bat`）

| 設定 | 最初の値 | 説明 |
| :--- | :--- | :--- |
| `SEVEN_ZIP` | `C:\Program Files\7-Zip\7z.exe` | 7-Zipを別の場所にインストールした場合は、その場所に書き換えます。 |
| `PASS_LENGTH` | `12` | パスワードの文字数です。 |
| `-mem=ZipCrypto` | `ZipCrypto` | 暗号化の方式です。この方式なら、受け取った人はWindowsの標準機能で開けます。より強い暗号化にしたい場合は `-mem=AES256` に書き換えます（受け取った人にも7-Zipなどが必要になります）。 |

`ppap.bat` を書き換えて保存するときは、文字コードを必ず **UTF-8** にしてください。ほかの文字コード（Shift-JISなど）で保存すると、日本語のフォルダ名をうまく扱えなくなることがあります。

### Mac / Linux版（`ppap.sh`）

| 設定 | 最初の値 | 説明 |
| :--- | :--- | :--- |
| `PASS_LENGTH` | `12` | パスワードの文字数です。 |
| `ENCRYPTION` | `ZipCrypto` | 暗号化の方式です。この方式なら、受け取った人はWindowsの標準機能で開けます。より強い暗号化にしたい場合は `AES256` に書き換えます（7-Zipのインストールが必要です。受け取った人にも7-Zipなどが必要になります）。 |

Mac / Linux版は、ZIPファイルの中の日本語のファイル名が、Windowsで開いても文字化けしないように記録します。Macが自動で作る `.DS_Store` というファイルはZIPに入れません。
