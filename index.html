PPAP省力化プロジェクト

指定したフォルダ直下にあるサブフォルダごとに、中身をパスワード付きのZIPファイルへ一括圧縮し、ファイル名とパスワードの対応表をCSVで出力するツールです。パスワードの生成もすべて行います。Windows版（ppap.bat）と Mac / Linux版（ppap.sh）があります。

PPAP（パスワード付きZIPでのファイル交換）を推奨するものではありません。とはいえ、取引先の指定によりPPAPしなければならないこともあるので、その業務負担を低減するために作成・公開しているものです。

ppap.bat をダウンロード ppap.sh をダウンロード GitHub リポジトリ

主な機能

  • サブフォルダ単位での一括ZIP化: 対象フォルダ直下の各サブフォルダの中身を サブフォルダ名.zip として圧縮します（空のフォルダは自動的にスキップされます）。
  • パスワードの自動生成: 視認性の高いランダムな英数字（デフォルト12桁、判別しづらい 1 / l / I / 0 / O を除外）をフォルダごとに個別生成します。
  • パスワード一覧のCSV出力: 圧縮したZIPファイル名とパスワードの組み合わせを password_list_YYYYMMDD_HHMMSS.csv（UTF-8 BOM付き・Excel対応）として出力します。
  • 柔軟なフォルダ指定: ドラッグ＆ドロップ、パス入力、カレントフォルダの自動選択に対応しています（Mac / Linux版はターミナルへのドラッグ＆ドロップ）。

事前準備

圧縮処理に 7-Zip を使用します。事前にインストールを行ってください。

  1. 7-Zip公式サイト からインストーラーをダウンロードします。
  2. 標準設定（C:\Program Files\7-Zip\）のままインストールします。
  • Mac: 追加のインストールは不要です（標準で入っている zip と perl を使います）。
  • Linux: zip と perl を使います。zip が入っていない場合はインストールしてください（例: sudo apt install zip）。
  • 暗号化方式を AES256 に変更する場合のみ、7-Zipが必要です（Mac: brew install sevenzip、Linux: sudo apt install p7zip-full など）。

使い方

1. ドラッグ＆ドロップで実行

圧縮したいサブフォルダ群が入っている親フォルダを、ppap.bat のアイコン上にドラッグ＆ドロップします。自動的に処理が開始されます。

2. ダブルクリックで実行（カレントフォルダ／パス指定）

  1. ppap.bat をダブルクリックして起動します。
  2. 対象フォルダのパス入力を求められます。
    • カレントフォルダを対象にする場合: 何も入力せずそのまま Enter キーを押します。
    • 任意のフォルダを対象にする場合: フォルダパスを入力（またはウィンドウ内に対象フォルダをドラッグ＆ドロップ）して Enter キーを押します。

3. コマンドプロンプトから実行

引数に対象フォルダのパスを指定して実行することも可能です。

ppap.bat "C:\Users\username\Desktop\TargetFolder"

ターミナルで ppap.sh を実行します。以下は、ダウンロードフォルダに ppap.sh を保存した場合の例です。

1. フォルダを指定して実行

bash ~/Downloads/ppap.sh "/Users/username/Desktop/TargetFolder"

2. 対話形式で実行（カレントフォルダ／パス指定）

  1. ターミナルで bash ~/Downloads/ppap.sh を実行します。
  2. 対象フォルダのパス入力を求められます。
    • カレントフォルダを対象にする場合: 何も入力せずそのまま Enter キーを押します。
    • 任意のフォルダを対象にする場合: フォルダパスを入力（またはターミナルに対象フォルダをドラッグ＆ドロップ）して Enter キーを押します。

カスタマイズ

ppap.bat をテキストエディタで開き、冒頭の設定項目やオプションを編集することで動作を変更できます。

設定項目 / 箇所デフォルト値説明
SEVEN_ZIPC:\Program Files\7-Zip\7z.exe7-Zipのインストール先が異なる場合にパスを変更します。
PASS_LENGTH12自動生成するパスワードの文字数を指定します。
-mem=ZipCryptoZipCryptoWindows標準のエクスプローラーで解凍できる暗号化方式です。より強固な暗号化が必要な場合は -mem=AES256 に書き換えてください（解凍側にも7-Zip等が必要になります）。

ppap.sh をテキストエディタで開き、冒頭の設定項目を編集することで動作を変更できます。

設定項目デフォルト値説明
PASS_LENGTH12自動生成するパスワードの文字数を指定します。
ENCRYPTIONZipCryptoWindows標準のエクスプローラーで解凍できる暗号化方式です。より強固な暗号化が必要な場合は AES256 に書き換えてください（7-Zipが必要です。解凍側にも7-Zip等が必要になります）。

注意事項

  • 既存ファイルの上書き: 出力先に同名の .zip ファイルが既に存在する場合、確認なしで上書きされます。
  • パスワードCSVの管理: 出力されたCSVファイルには平文でパスワードが記載されています。外部への誤送信や共有フォルダへの放置にご注意ください。
  • 文字コードについて: ppap.bat を編集・保存する際は、文字コードを必ず UTF-8 に設定してください（Shift-JIS等で保存すると日本語フォルダ名が正しく処理されない場合があります）。
  • Mac / Linux版のファイル名の扱い: ZIP内の日本語ファイル名は、Windowsで解凍しても文字化けしない形式に補正して記録します。Macが自動で作る .DS_Store は圧縮対象から除外します。
